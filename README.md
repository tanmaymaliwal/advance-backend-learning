# Advanced Backend Engineering

A hands-on repository documenting my journey into backend engineering, distributed systems, containerization, caching, and scalable application architecture.

The goal is to understand not only how to build backend services, but also how to make them reliable, maintainable, performance, and production-ready.

## Learning Modules

### Level 1 — Docker Fundamentals

Exploring containerization by building and running a Node.js backend application using Docker.

**Concepts implemented:**
- Writing a `Dockerfile` to define the application environment.
- Building Docker images and running containers.
- Containerizing a Node.js application and running the server inside a container.
- Understanding image creation, container execution, and application startup.
- Managing container-related files and configuration using `.dockerignore`.

### Level 2 — Redis Caching & MongoDB

Implementing a Node.js and Express backend integrated with MongoDB and Redis to explore database operations and caching.

**Concepts implemented:**
- Connecting a backend application to MongoDB.
- Creating user records and retrieving data from the database.
- Integrating Redis as an in-memory data store.
- Implementing Redis-backed data retrieval and exploring cache hits and cache misses.
- Understanding how caching can reduce repeated database queries and improve read performance.
- Using Docker Compose to configure and run backend dependencies.

## Technology Stack

**Language:** JavaScript  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Caching:** Redis  
**Containerization:** Docker, Docker Compose  
**Version Control:** Git, GitHub

## Objective

Build a strong foundation in backend engineering by implementing concepts, debugging real-world development issues, and understanding the design decisions behind efficient, reliable, and scalable backend systems.
